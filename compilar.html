Compílalotú

Todavía no hay versiones para descargar. NeXo 2 se compila desde el código en unos minutos.

Necesitas

  1. Visual Studio 2022Con «Desarrollo para el escritorio con C++».
  2. CMake 3.25+El de cmake.org o el que trae Visual Studio.
  3. GitPara descargar el código y sus submódulos.
  4. Una GPU con VulkanOpcional por ahora: sin ella, NeXo dibuja por software.
cmd
> git clone --recursive https://github.com/NeXoNetwork/NeXo2-emu.git
> cd NeXo2-emu
> cmake -S . -B build -G "Visual Studio 17 2022" -A x64
> cmake --build build --config Release
> build\Release\NeXo2.exe

Después arrastra un .nro a la ventana (o «Cargar NRO») y pulsa Run o F5. Si tienes devkitPro instalado, usa el CMake de Windows, no el de MSYS2.
