Un emulador de Switch 2, escrito desde cero.

NeXo 2 es código abierto en C++20. Cada pieza —la CPU, el kernel, la GPU— está hecha a mano, documentada y comprobada con tests. Todavía no ejecuta juegos comerciales; sí homebrew, y ya dibuja en 3D.

02

Por dentro

De la instrucción ARM64 al píxel en tu pantalla. Cada paso tiene su propia página en la documentación.

  1. CPU

    ARMv8.2 completo

    Enteros, coma flotante con las reglas exactas de ARM, NEON, AES/SHA y CRC32. Un fuzzer lo compara con un ARM de referencia instrucción a instrucción.

  2. JIT

    Traducción a x86-64

    dynarmic convierte el código ARM64 en código del PC y lo ejecuta directamente. Lo que no sabe hacer, lo hace el intérprete.

  3. HLE

    Kernel e IPC

    Llamadas al sistema, mensajes HIPC/CMIF con dominios, 6 núcleos emulados con mutex y condvar, y los servicios que usa libnx: sm, applet, hid, time, fs, vi y nvdrv.

  4. GPU

    Shaders y texturas

    Decodificador e intérprete de shaders Maxwell, rasterizador por software en varios hilos, texturas BC1–BC5, mipmaps, MSAA y profundidad. Vulkan, en camino.

04

        
Compílalo tú

        
Aún no hay versiones para descargar. Con Visual Studio 2022, CMake y Git se compila en unos minutos.

        Leer la documentación
      


      

        
cmd


> git clone --recursive https://github.com/NeXoNetwork/NeXo2-emu.git
> cd NeXo2-emu
> cmake -S . -B build -G "Visual Studio 17 2022" -A x64
> cmake --build build --config Release
> build\Release\NeXo2.exe
