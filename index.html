Qué hace hoy (y qué no)

NeXo 2 está en una fase temprana. Preferimos contarlo tal cual.

Ya funciona

  • Homebrew .nro hecho con libnx
  • Consola de texto y framebuffer en la ventana «Pantalla»
  • Mandos: teclado y mandos del PC
  • Tarjeta SD emulada con una carpeta del PC
  • Herramientas de depuración: registros, memoria, paso a paso

Todavía no

  • Juegos comerciales
  • GPU y gráficos 3D (backend Vulkan)
  • Audio
  • Varios hilos a la vez
  • Velocidad real: con el intérprete va a pocas imágenes por segundo

Cómo está hecho

Cada parte está escrita desde cero y documentada, para que se pueda aprender de ella.

CPU ARM64

Intérprete propio de enteros, coma flotante y NEON. Las instrucciones SIMD se comparan bit a bit con un ARM de referencia.

Kernel HLE

Las llamadas al sistema (SVC) del kernel de la consola, el mapa de memoria del proceso y el arranque de homebrew.

IPC y servicios

Mensajes HIPC, CMIF y TIPC con dominios. Servicios sm:, applet, hid, time, fs, vi y nvdrv.

Pantalla

Cola de buffers del binder, memoria nvmap y conversión del formato en bloques de la GPU (block linear) a una imagen normal.

Mandos

El teclado y los mandos del PC (SDL3) se escriben en la memoria compartida de hid, igual que en la consola real.

Tarjeta SD

Una carpeta del PC hace de sdmc:/. Los programas pueden leer y escribir archivos, pero nunca salir de ella.

Compílalo tú

Aún no hay versiones descargables: NeXo 2 se compila desde el código.

Requisitos (Windows)

  • Visual Studio 2022 con «Desarrollo para el escritorio con C++»
  • CMake 3.25+
  • Python 3 (lo usa el JIT para generar sus tablas)
  • Git

Después, arrastra un .nro a la ventana o usa «Cargar NRO» y pulsa Run (F5).

cmd
git clone --recursive https://git.joustech.space/NeXo/NeXo2-emu.git
cd NeXo2-emu
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
build\Release\NeXo2.exe
