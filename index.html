Qué hace hoy (y qué no)

NeXo 2 está en una fase temprana. Preferimos contarlo tal cual.

Ya funciona

  • Homebrew .nro hecho con libnx: arranca, dibuja y responde al mando
  • CPU ARM64 completa (enteros, coma flotante, NEON, criptografía) y un JIT
  • Hilos repartidos entre 6 núcleos emulados
  • GPU, fase 1: comandos, macros, borrados, copias y blits
  • Mandos, tarjeta SD con una carpeta del PC y herramientas de depuración

Todavía no

  • Juegos comerciales
  • Dibujar en 3D: shaders y backend Vulkan (GPU fase 2)
  • Audio
  • Formatos de juego (NSO, NCA)

Cómo está hecho

Cada parte está escrita desde cero, documentada y comprobada con tests, para que se pueda aprender de ella.

CPU ARM64

Intérprete propio de todo ARMv8.2: enteros, coma flotante con las reglas exactas de ARM, NEON, AES/SHA y CRC32. Se compara con un ARM de referencia instrucción a instrucción.

JIT

dynarmic traduce el código ARM64 a x86-64 y lo ejecuta directamente: seis veces más rápido. Lo que no sabe hacer lo hace el intérprete.

Hilos

Planificador con 6 núcleos emulados, prioridades, mutex y variables de condición como libnx, y detección de bloqueos.

GPU

Dispositivos nvhost, canales, pushbuffers y macros de la GPU Maxwell; borra render targets, copia y escala imágenes. Probado con las macros reales de deko3d.

Kernel HLE e IPC

Llamadas al sistema (SVC), mensajes HIPC/CMIF/TIPC con dominios y los servicios del arranque de libnx: sm, applet, hid, time, fs, vi y nvdrv.

Pantalla, mandos y SD

Cola de buffers del binder, imágenes en bloques de la GPU, mandos del PC en la memoria compartida de hid y una carpeta del PC como sdmc:/.

Compílalo tú

Aún no hay versiones descargables: NeXo 2 se compila desde el código.

Requisitos (Windows)

  • Visual Studio 2022 con «Desarrollo para el escritorio con C++»
  • CMake 3.25+
  • Git

La primera compilación tarda unos minutos más (el JIT). Después, arrastra un .nro a la ventana o usa «Cargar NRO» y pulsa Run (F5).

cmd
git clone --recursive https://git.joustech.space/NeXo/NeXo2-emu.git
cd NeXo2-emu
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
build\Release\NeXo2.exe
