Arquitectura de Alto Rendimiento

Diseñado desde cero en C++20 optimizado para exprimir el máximo potencial de CPUs y GPUs modernas.

Recompilación JIT Core

Traducción dinámica de instrucciones ARM64v9 a x86-64 y ARM de escritorio en tiempo real para un rendimiento cercano al nativo.

Backend Vulkan 1.3

Pipeline gráfico avanzado con soporte experimental para Ray Tracing, DLSS / FSR Upscaling y descompresión de texturas por hardware.

Mapeo de Mandos Avanzado

Soporte para DualSense, Xbox Controller, Switch Pro Controller y giroscopio HD Rumble integrado para máxima inmersión.

Interfaz Fluida UI/UX

Diseño limpio inspirado en el sistema operativo Switch 2, rápido gestor de biblioteca de juegos y perfiles por título.

Requisitos del Sistema

Requisitos Mínimos

  • CPU: Intel Core i5-10400 / AMD Ryzen 5 3600
  • GPU: NVIDIA GTX 1060 (6GB) / AMD RX 580
  • RAM: 16 GB DDR4
  • API Gráfica: Vulkan 1.3 Driver Compliant

Requisitos Recomendados

  • CPU: Intel Core i7-13700K / AMD Ryzen 7 7800X3D
  • GPU: NVIDIA RTX 3070 / AMD RX 6800 XT
  • RAM: 32 GB DDR5
  • Almacenamiento: NVMe SSD High Speed
